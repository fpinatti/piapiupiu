# Implementation Plan: Wingspan Scorepad Asia Duo Mode Track Scoring

**Branch**: `008-scorepad-asia-duo-mode` | **Date**: 2026-11-01 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/008-scorepad-asia-duo-mode/spec.md`

## Summary

Add the missing scoring category for the *Wingspan: Asia* expansion Duo Mode ("Modo Duo") to the unified 2-player scorepad. This adds a ninth row to the table with a subtle `"Ásia"` expansion badge, an authentic watercolor droplet icon with the iconic yin-yang duo token glyph, and real-time point summation. Leaving the field blank or `0` evaluates to 0 without penalty, preserving zero-friction scoring for games played without the Asia expansion.
